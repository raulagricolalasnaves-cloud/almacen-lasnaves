───────────────────────────────────────────────────────────
 COMO SUBIRLOS (opcion facil, arrastrando)
───────────────────────────────────────────────────────────
1. Entra a github.com/raulagricolalasnaves-cloud/almacen-lasnaves
2. Boton "Add file" -> "Upload files"
3. Arrastra la carpeta completa que sale de este zip
   (o los archivos uno por uno respetando la ruta)
4. Abajo escribe: "Modulo de compras: recepcion y costeo"
5. "Commit changes"

GitHub reconoce las rutas y reemplaza cada archivo donde va.

───────────────────────────────────────────────────────────
 DESPUES DE SUBIR
───────────────────────────────────────────────────────────
· Espera 1-2 minutos: GitHub Pages tarda en publicar.
· Abre la app y recarga con Ctrl + Shift + R
  (si no, el navegador te sigue mostrando la version vieja).
· Debe aparecer una pestaña nueva "Compras" junto a Pedidos.

───────────────────────────────────────────────────────────
 SI ALGO NO SE VE
───────────────────────────────────────────────────────────
· No aparece la pestaña -> falto subir index.html, o el
  navegador tiene cache. Ctrl + Shift + R.
· Aparece pero sale vacia o con error -> abre la consola del
  navegador (tecla F12, pestaña "Console") y pasa el mensaje.
· Dice "permission denied" -> falto correr 11_permisos_api.sql
  en Supabase.

───────────────────────────────────────────────────────────
 PARA VOLVER ATRAS
───────────────────────────────────────────────────────────
En GitHub, pestaña "Commits", entras al commit anterior y le
das "Revert". Tus datos en Supabase no se tocan: este paquete
solo cambia la interfaz.
